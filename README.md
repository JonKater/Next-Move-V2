# Next Move

Local-first Personal Daily Execution Coach that helps choose the next action.

Answering one narrow, powerful question: *"Given my available time, energy, and location/context, what should I do next?"*

## Features

- **Morning Compass**: Calibrate your daily baseline with Usable Time, Energy Level (Low, Medium, High), and Available Context (Anywhere, Computer, Phone, Errands).
- **Deterministic Next Move Recommendation**: Mathematically scores active tasks against your daily context, factoring in duration fit, energy demands, urgency, and strategic relevance with clear, transparent explanations.
- **Focus Mode**: Distraction-free execution screen with real-time "Park a thought..." scratchpad.
- **Action Management**:
  - Direct action creation with auto-assigned Inbox.
  - "Too big": Atomically split oversized tasks into bite-sized sub-actions.
  - "Not now": Defer tasks for the current day without permanent loss; re-eligible on the next day.
- **Close-and-Learn (Evening Review)**: Daily reflection log capturing completed work and blockers.
- **Local-First Persistence**: Durable client-side storage with zero tracking or external account requirements.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS (Material 3 color architecture)
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

```bash
npm install
npm run dev
```

The application runs on `http://localhost:3000`.
